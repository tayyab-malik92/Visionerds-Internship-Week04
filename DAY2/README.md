
# Day 17 – ReAct AI Agent

##  Overview

Built a **ReAct (Reason → Act → Observe)** AI Agent using the Groq API. The agent can reason about a query, select the appropriate tool, execute it, observe the result, and continue until it reaches the final answer.

##  Features

- ReAct (Reason → Act → Observe) Loop
- Automatic Function Calling
- Multiple Tool Chaining
- Reasoning Trace
- Conversation Memory
- Groq Integration

## 🛠 Tools

- 🧮 Calculator
- 📝 Word Counter
- 🔤 Character Counter


## ▶️ Run

```bash
pip install -r requirements.txt
python main.py
```
